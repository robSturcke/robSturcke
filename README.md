# Rob Sturcke

I've been writing software since I was 11. I still like shipping the whole product, not a slide about one.

These days I run [Ionic Cactus](https://ioniccactus.com), a small SaaS company that grew out of RSVision, my freelance practice from 2012 to 2025. It started as a wrap-up of freelance clients and months of planning and assessing which fields to build in. [DueFleet](https://duefleet.com) is the product I have actually spent months building: AI fleet maintenance across web, a live iOS app, database, billing, and an in-app AI agent that helps fleet managers create and update their work. I built it solo. Doing that taught me a lot about owning every layer, and about the help I'd want from a good team.

Other ideas were assessed under Ionic Cactus. DueFleet is the one that became a real product.

Before that I was a Software Engineer at Encyclopaedia Britannica (Apr 2022 to Oct 2026). I led analysis and built full-stack prototypes (React frontends, Python FastAPI backends) for AI and automation across the company's apps, then shipped pieces of that work: Britannica Studio's dynamic presentation styling (AI-driven text, media, and layouts), Expedition Learn's move from Create React App to Next.js, on-device encryption and a media pipeline for the Escola app, and infrastructure automations for Git workflows and SOC 2 compliance processes.

Earlier I was a contract UI engineer on Apple's Global Network Security team (May 2021 to Apr 2022), and a Full Stack Engineer at Holman (Mar 2017 to Sep 2020).

I use AI agents in my own design, build, and ship loop. The part I care about is when the model can change real data, with tests and guardrails around it.

I'm looking for a remote Product Engineer or Software Engineer role where a small team wants someone who will take a feature from idea to production.
